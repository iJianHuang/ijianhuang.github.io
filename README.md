# Jian's ML Code Camp

Welcome to my collection of interactive machine learning experiments and browser-based demos. This repository is a hands-on playground for learning how ML models work in the browser, from classic regression and classification techniques to self-driving car simulations and computer vision examples.

## What you'll find here

- Interactive demos powered by JavaScript and TensorFlow.js
- Visual machine learning examples that make training behavior easier to understand
- Small, approachable projects designed for learning and experimentation
- A mix of practical AI demos and educational coding exercises

## Explore the projects

- [SelfDrivingCar](SelfDrivingCar/index.html) — watch an AI car learn to navigate a road using sensors and neural networks
- [HouseSales/LinearRegression](HouseSales/LinearRegression/index.html) — explore linear regression and house price prediction
- [HouseSales/MultiClasses](HouseSales/MultiClasses/index.html) — see multiclass classification in action
- [HouseSales/KNN](HouseSales/KNN/index.html) — try a k-nearest-neighbors example with real data
- [WebCam](WebCam/index.html) — experiment with webcam-based ML in the browser

## Why this repo exists

This project is meant to make machine learning feel tangible and approachable. Instead of reading only theory, you can run small demos, inspect the code, tweak parameters, and see how changes affect model behavior in real time.

## Start exploring

Open the main site at [index.html](index.html) to browse the demos, or dive directly into a project folder to experiment with the code. Whether you're curious about neural networks, prediction models, or browser-based AI, there is something here to explore.

## Learning mindset

This repository is built for curiosity. Try things, break things, adjust the logic, and learn from what you observe. Each demo is a small step toward understanding how machine learning works in practice.

If you're here to learn, build, or just explore, enjoy the journey — and feel free to experiment with the code as you go.
